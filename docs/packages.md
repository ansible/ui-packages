# Package inventory

The repository publishes the following packages to npm. The package README
files contain API details and examples.

| Package | Purpose |
| --- | --- |
| [`@ansible/ui-plugin-sdk`](https://github.com/ansible/ui-packages/tree/main/packages/ui-plugin-sdk) | Interfaces for defining UI plugins and their integrations. |
| [`@ansible/ui-plugin-loader`](https://github.com/ansible/ui-packages/tree/main/packages/ui-plugin-loader) | Helpers for loading Ansible UI plugins. |
| [`@ansible/ui-plugin-pf5`](https://github.com/ansible/ui-packages/tree/main/packages/ui-plugin-pf5) | Helpers for building plugin interfaces with PatternFly 5. |
| [`@ansible/eslint-plugin`](https://github.com/ansible/ui-packages/tree/main/packages/eslint-plugin) | Portable ESLint rules for Ansible frontend packages. |
| [`@ansible/md-link-lint`](https://github.com/ansible/ui-packages/tree/main/packages/md-link-lint) | CLI and library for checking local file and heading links in Markdown. |

## Example project

[`examples/ui-plugin-example-pf5`](https://github.com/ansible/ui-packages/tree/main/examples/ui-plugin-example-pf5)
shows how the UI Plugin SDK and PatternFly 5 package fit together. The example
is a workspace in this repository; it is not published to npm.
