# Ansible UI Packages

Ansible UI Packages is a monorepo of reusable npm packages and developer tools
from the Red Hat Ansible UI team. The packages support building extensions for
Ansible Automation Platform (AAP) and maintaining Ansible frontend projects.

The repository uses npm workspaces and Nx. Published packages live in
[`packages/`](https://github.com/ansible/ui-packages/tree/main/packages), and
the `examples/` directory contains a sample PatternFly 5 UI plugin.

## Start here

- Browse the [package inventory](packages.md) to find a package.
- Follow the [usage guide](usage.md) to install a package or run the example.
- Read the [contributor guide](contributing.md) to set up the repository and
  preview documentation changes.
